# LEDSetup

LEDSetup управляет одной аналоговой RGB-лентой семейства Zengge LEDnetWF по Bluetooth Low Energy из Windows. Можно выбрать ленту, включать и выключать её, задавать сплошной RGB-цвет и синхронизировать цвет со средним цветом выбранного монитора.

Это не приложение для адресных лент: вся лента получает один общий цвет — без сегментов, зон и эффекта «подсветки по краям экрана».

## Требования

- Windows с доступным Bluetooth LE;
- Python 3.11+;
- совместимый контроллер LEDnetWF / аналоговая RGB-лента.

Работа проверена на Smartbuy `SBL-RGBW-KIT-75`. Рекламируемое Bluetooth-имя устройства может меняться, поэтому приложение сохраняет адрес, а не имя.

## Установка и запуск

В PowerShell:

```powershell
cd app
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
ledsetup
```

Команда без аргументов открывает графическое окно. Нажмите **«Найти ленту»**, выберите устройство из списка, подключитесь и задайте цвет. Если контроллер уже занят, закройте ZENGGE и отключите устройство в настройках Windows, затем повторите поиск.

## Командная строка

```powershell
ledsetup scan                         # поиск и выбор устройства
ledsetup scan --index 1               # выбрать первую строку без вопроса
ledsetup color 255 40 40              # установить RGB-цвет
ledsetup off                          # выключить ленту
ledsetup sync --monitor 1             # передавать средний цвет экрана
ledsetup sync --monitor 1 --seconds 30
ledsetup gatt                         # вывести найденные GATT-характеристики
```

После `scan` выбранный адрес сохраняется и используется следующими командами. Для разового обращения к конкретному устройству добавьте `--address E4:98:BB:6B:1A:AC` к `color`, `off`, `sync` или `gatt`. Справка: `ledsetup --help`.

## Синхронизация с экраном

**«Экран → лента»** и команда `sync` берут средний RGB-цвет всего выбранного монитора и отправляют его на всю ленту. Это подходит для атмосферной подсветки, но не воспроизводит отдельные области изображения. Остановите синхронизацию кнопкой в окне или `Ctrl+C` в терминале; лента останется последнего цвета.

## Статус протокола

RGB и `off` визуально подтверждены на указанном комплекте. Кадры `on` и `color --hsv` пока являются гипотезами и могут не сработать. Точные сведения о совместимости, GATT UUID и проверенных кадрах — в [docs/protocol-notes.md](docs/protocol-notes.md).
