# GlowLink

GlowLink — Windows-приложение для управления **одной аналоговой RGB-лентой** с BLE-контроллером
Zengge LEDnetWF. Можно выбрать контроллер, включить или выключить ленту, задать единый цвет и
передавать на неё средний цвет одного монитора.

> Адресные ленты, зоны, несколько независимых устройств и Ambilight по контуру экрана не
> поддерживаются. Полные границы — в [описании продукта](docs/product-scope.md).

## Начать пользоваться

### Готовое приложение

Скачайте `GlowLink.exe` из [Releases](../../releases) и запустите его двойным щелчком. Python
не нужен. Для интерфейса требуется Microsoft Edge WebView2 Runtime; обычно он уже есть в
Windows 10 и 11.

1. Включите Bluetooth в Windows и подайте питание на контроллер.
2. Откройте GlowLink и нажмите **«Найти ленту»**.
3. Выберите найденное устройство и подключитесь.
4. Выберите цвет, выключите ленту или включите синхронизацию экрана.

GlowLink сохраняет **BLE-адрес**, а не имя устройства: рекламируемое имя может меняться. Если
подключение не удаётся, закройте приложение ZENGGE и отключите контроллер в настройках Windows —
он может быть занят другим приложением.

### Запуск из исходников

Нужны Windows с Bluetooth LE, Python 3.12+ и совместимый контроллер с аналоговой RGB-лентой.

```powershell
cd app
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
ledsetup
```

## Командная строка

Сначала найдите и сохраните контроллер. Затем следующие команды используют сохранённый адрес.

```powershell
ledsetup scan
ledsetup color 255 40 40
ledsetup off
ledsetup sync --monitor 1
```

Для разового вызова можно явно передать адрес:

```powershell
ledsetup color 255 40 40 --address E4:98:BB:6B:1A:AC
```

| Команда | Назначение |
| --- | --- |
| `ledsetup` или `ledsetup gui` | Открыть окно управления. |
| `ledsetup scan` | Найти BLE-устройства и выбрать контроллер. |
| `ledsetup color R G B` | Установить один цвет всей ленты. |
| `ledsetup off` | Выключить ленту. |
| `ledsetup sync --monitor 1` | Передавать средний цвет указанного монитора; остановка — `Ctrl+C`. |
| `ledsetup gatt` | Показать GATT-службы для диагностики. |

`sync` не создаёт эффект подсветки по краям экрана: вся лента получает один усреднённый цвет.
Команды `on` и `color --hsv` экспериментальные — не используйте их как надёжный способ
управления.

## Совместимость и помощь

RGB и `off` визуально проверены только на Smartbuy `SBL-RGBW-KIT-75` (Zengge LEDnetWF).
Проверенный статус и ограничения — в [матрице совместимости](docs/device-compatibility.md).
