## Статусы достоверности

- **Поддерживается** — результат повторяемо проверен на физическом устройстве и внесён в
  матрицу совместимости.
- **Экспериментально** — команда или наблюдение есть в коде либо исследованиях, но не
  подтверждено устройством.
- **Гипотеза** — предварительное предположение; не считайте его поддерживаемым поведением.
