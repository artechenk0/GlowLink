# Story

## Бизнес-цель

Пользователь быстро понимает, подключена ли сохранённая LED-лента, до попытки изменить цвет.

## User story

Как пользователь, я вижу выбранное устройство и состояние «подключено» или «не подключено»,
чтобы понимать, доступно ли управление лентой.

## Границы и non-goals

Статус не запускает подключение, не выполняет GATT-операций и не меняет модель управления одной
лентой.

## Критерии успеха

- При выбранном устройстве UI показывает имя, адрес и актуальное состояние соединения.
- Без выбранного устройства UI показывает понятное пустое состояние.
- После подключения или отключения UI получает обновлённое состояние.
