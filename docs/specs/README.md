# SDD-спецификации

Каждая значимая задача хранится в отдельной папке `docs/specs/<slug>/` с четырьмя файлами:
`README.md`, `story.md`, `technical.md` и `tasks.md`. Порядок работы описан в
[SDD-гайде](../standards/sdd.md).

Начните с [_template](./_template/README.md). Учебный пример —
[example-device-status](./example-device-status/README.md).
