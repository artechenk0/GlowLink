# 0004. UI не знает GATT

Статус: Accepted
Дата: 2026-08-30

## Контекст
UUID, свойства характеристик и Bleak относятся к транспортному слою.

## Решение
CLI, GUI и Web UI вызывают сценарии приложения и получают готовые состояния/сообщения.

## Последствия
Изменение GATT не требует менять UI; тесты UI используют сессию или фейки, а не BLE-клиент.
