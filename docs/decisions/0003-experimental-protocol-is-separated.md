# 0003. Экспериментальный протокол отделён

Статус: Accepted
Дата: 2026-08-30

## Контекст
Часть LEDnetWF-кадров взята из реверса и не проверена на комплекте.

## Решение
Подтверждённые и экспериментальные команды помечаются раздельно в коде и документации.

## Последствия
Эксперимент не становится стабильным без hardware-проверки и обновления матрицы совместимости.
