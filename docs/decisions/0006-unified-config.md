# 0006. Единая конфигурация приложения

Статус: Accepted
Дата: 2026-08-31

## Контекст

Настройки и выбранное BLE-устройство хранились раздельно, а UI напрямую управлял JSON-файлами.

## Решение

Использовать типизированный `AppConfig` и единый `ConfigStore` с атомарной записью в
`LEDSETUP_CONFIG_FILE` или `%LOCALAPPDATA%/ledsetup/config.json`. Изменения проходят через
`ConfigService`, который хранит состояние в памяти и предоставляет детерминированный `flush()`.
Формат имеет `schema_version`; неизвестные поля игнорируются, а повреждение одного поля заменяет
default только для него. Старые файлы не мигрируются.

## Последствия

CLI, GUI и Web UI видят одну модель состояния и один формат хранения. Выбор устройства,
монитор и настройки сохраняются сразу. Быстрые изменения цвета не создают серию файловых
операций; последний цвет сохраняется при штатном завершении через `flush()`.
