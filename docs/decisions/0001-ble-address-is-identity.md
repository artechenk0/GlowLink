# 0001. BLE-адрес — идентификатор

Статус: Accepted
Дата: 2026-08-30

## Контекст
Рекламируемое имя BLE-устройства может меняться.

## Решение
Сохранять и выбирать устройство по BLE-адресу. Имя — только last-seen подсказка при scan.

## Последствия
Интерфейсы не должны считать точное имя устройства ключом совместимости.
