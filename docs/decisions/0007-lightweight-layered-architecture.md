# 0007. Лёгкая слоистая архитектура

Статус: Accepted
Дата: 2026-08-31

## Контекст

ADR 0005 создал правильное направление зависимостей, но отдельные DTO, store-порты и классы
для каждого короткого действия существовали параллельно с прямыми вызовами адаптеров из UI.
Это увеличивало код, не создавая рабочей границы.

## Решение

Сохранить `domain`, `application`, `adapters`, `presentation` и bootstrap, но использовать один
`GlowLinkApplication` и только три внешних порта: BLE, screen и config repository. Конкретные
адаптеры собираются только в bootstrap. Presentation не импортирует adapters. Внутренний Python
API и прежние корневые модули не являются контрактом совместимости.

## Последствия

CLI, menu и GUI выполняют одни сценарии. BLE-операции сериализованы, sync и reconnect имеют одну
реализацию, а зависимости слоёв проверяются автоматически. Новый слой или порт требует реальной
точки замены; класс на каждый метод не используется.
