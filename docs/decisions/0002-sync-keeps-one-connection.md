# 0002. Sync удерживает одно соединение

Статус: Accepted
Дата: 2026-08-30

## Контекст
Переподключение для каждого кадра снижает надёжность и частоту sync.

## Решение
`BleSession` открывает соединение один раз и пишет кадры до остановки sync или разрыва.

## Последствия
При stale link допустимо одно контролируемое переподключение к тому же адресу.
