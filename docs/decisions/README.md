# Architecture Decision Records

ADR фиксирует решение, которое меняет архитектурную границу, совместимость, протокол или
поддерживаемое поведение. Файлы именуются `NNNN-краткое-название.md`; новый ADR не переписывает
принятое решение, а заменяет его отдельной записью.

```md
# NNNN. Название

Статус: Accepted
Дата: YYYY-MM-DD

## Контекст
Краткая проблема.

## Решение
Принятое правило.

## Последствия
Что это упрощает, ограничивает или требует проверить.
```
