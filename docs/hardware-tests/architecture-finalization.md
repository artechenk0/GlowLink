# Hardware check: architecture finalization

Статус: pending
Устройство: совместимый аналоговый RGB-контроллер

## Чек-лист

- [ ] `ledsetup scan --index N` находит и сохраняет адрес.
- [ ] `ledsetup color 255 0 0` и второй цвет используют корректный write UUID.
- [ ] `ledsetup off` выключает ленту.
- [ ] `ledsetup sync --monitor 1 --seconds 30` удерживает соединение и корректно завершается.
- [ ] GUI scan/connect и быстрое перемещение color picker заканчиваются последним цветом.
- [ ] GUI sync stop/start не запускает два параллельных цикла; после stop остаётся последний цвет.
- [ ] Закрытие GUI не оставляет процесс и BLE-соединение активными.

После прогона записать дату, Windows/Bluetooth environment, фактический результат каждого шага
и ссылку из матрицы совместимости. До этого документация не утверждает повторную hardware
верификацию архитектурной версии.
