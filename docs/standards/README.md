# Стандарты проекта

Этот раздел — единый источник рекомендаций GlowLink для участников проекта и агентских сред.
`AGENTS.md` содержит обязательный минимум для агентов, а специализированные skills описывают
свои процедуры; правила проекта не дублируются в них.

| Документ | Когда использовать |
| --- | --- |
| [Разработка](development.md) | Меняете код, тесты, архитектуру или готовите pull request. |
| [Тексты](writing.md) | Создаёте, проверяете или обновляете любой текст проекта. |
| [Gitflow](gitflow.md) | Выбираете ветку, готовите PR или выпускаете релиз. |
| [SDD](sdd.md) | Изменение затрагивает поведение, протокол, GUI, совместимость или архитектуру. |

Новая агентская среда должна подключать этот раздел короткой ссылкой из своего файла инструкций,
а не копировать правила. Это сохраняет одинаковые требования для людей и агентов.
