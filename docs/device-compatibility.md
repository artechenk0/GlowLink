# Совместимость устройств

Здесь перечислены только результаты, подтверждённые на физическом устройстве. Сходство имени,
UUID или протокольная гипотеза не означают совместимость. BLE-адрес — идентификатор выбранного
устройства; рекламируемое имя служит лишь подсказкой.

## Проверенный контроллер

| Устройство | Тип подсветки | UUID: service / write / notify | Проверенные команды | Дата | Статус |
|---|---|---|---|---|---|
| Проверенный совместимый контроллер | Аналоговая RGB, `+ / R / G / B`, один общий цвет | `FFFF` / `FF01` / `FF02` | RGB `0B 31`, off `0B 3B 24` | 2026-08-25 | Поддерживается |

Полные UUID: `0000FFFF-0000-1000-8000-00805F9B34FB`,
`0000FF01-0000-1000-8000-00805F9B34FB`,
`0000FF02-0000-1000-8000-00805F9B34FB`.

Новые команды и UUID не считаются поддержанными без ручного прогона, записи даты, команд и
результата. Детали GATT и кадров — в
[protocol-notes.md](protocol-notes.md).

## Как добавить результат

Сохраните воспроизводимый ручной прогон в `docs/hardware-tests/`: модель и тип ленты, команды,
дату, наблюдаемый результат и ограничения. После этого добавьте краткую строку в таблицу выше.
