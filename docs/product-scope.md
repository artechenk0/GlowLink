# Границы продукта

GlowLink поддерживает Windows-приложение для **одной** аналоговой RGB-ленты с контроллером по
BLE. Доступны выбор устройства по адресу, подключение, выключение, один сплошной RGB-цвет и
синхронизация всей ленты со средним цветом одного монитора.

Не поддерживаются адресные ленты, отдельные светодиоды, сегменты и зоны, число LED, chip type,
smear, эффекты на пикселях, несколько независимо управляемых лент и Ambilight по краям экрана.
Синхронизация — это один усреднённый цвет, а не пространственная карта экрана.

Возможность расширяет scope, если добавляет иной тип ленты/контроллера, новую модель управления
цветом, несколько устройств, другую ОС либо эффекты, зависящие от положения LED. Перед такой
работой нужно обновить этот документ, принять ADR и определить способ проверки в матрице
совместимости. Непроверенная команда или UUID не считаются поддержкой.
